### 게임 제목
- **왁뿌수기**

### 개요
- **지뢰 찾기를 기반으로 한, ASMR 힐링 게임**
- 장르: 논리 퍼즐
- 플레이 방식: 싱글 플레이

### 목적
- 필드에서 **안전한 타일**과 **벌레가 있는 타일**을 구분한다.
- 타일에 표시되는 **숫자**를 통해 벌레의 위치를 추론한다.
- 벌레가 있다고 판단되는 타일에는 **느낌표 마크**를 설치하여 실수를 방지한다.
- 벌레가 있는 타일을 제외한 모든 안전한 칸을 개방하면 승리한다.

### 조작 방법
- 마우스 왼쪽 클릭: 타일 개방
- 마우스 오른쪽 클릭: 마크 설치 / 재클릭 시 제거
- 메뉴 조작 (마우스 왼쪽 클릭):
	 - 난이도 변경
	 - 게임 리셋
	 - 게임 종료

### 규칙
- 필드
	- 게임 화면에는 여러 개의 정사각형 타일로 구성된 격자가 존재한다.
	- 일부 타일에는 벌레가 숨겨져 있다.
	- 플레이어는 처음에는 타일의 내부 정보를 확인할 수 없다.
- 타일의 종류
1. 닫힌 타일
2. 빈 타일
3. 숫자 타일
4. 벌레 타일
5. 마크 타일
- 숫자의 의미
	- 한 타일에 표시된 숫자는 **상하좌우** 및 **대각선**을 포함한 **인접 8타일에 존재하는 벌레의 수**를 의미한다.
- 빈 칸 자동 개방

### 점수/ 승부 규칙
- 승리
  - 모든 안전한 타일을 개방하면 승리
  - 모든 벌레가 있는 타일에 반드시 마크를 설치해야 하는 것은 아니다.
- 패배
	- 벌레가 있는 타일을 클릭하면 즉시 패배

### 시작 조건
1. 게임 실행
2. 새로운 게임 시작
3. 벌레가 배치된 격자 랜덤 생성
4. 플레이어가 첫 번째 타일을 클릭하면서 게임이 시작된다.
	- **첫 번째 클릭이 벌레가 되지 않도록 배치를 조정**

### 종료 조건
- 승리 종료
	- 모든 안전한 타일 개방 → 승리 화면 표시
- 패배 종료
	- 벌레가 있는 타일 클릭 → 패배 화면 표시
- 기타 종료
	- 플레이어가 게임을 리셋
	- 플레이어가 게임을 종료

### 플레이어 행동
플레이어는 다음 행동을 반복
1. 타일 열기
닫힌 타일 클릭
해당 타일의 정보 확인
2. 숫자 분석
공개된 숫자 확인
주변 벌레의 위치 추론
3. 마크 표시
벌레가 있다고 판단한 타일에 마크
잘못 마크했다고 판단했다면, 마크를 제거
5. 안전한 칸 추론
예시로 숫자 1 주변에 확인되지 않은 타일이 하나뿐이라면, 해당 타일에 벌레가 있다고 판단할 수 있다.
6. 연쇄 개방
7. 위험 감수
확실한 정보가 없는 경우, 여러 가능성 중 하나를 선택해야 한다.
일부 상황에서는 논리적 추론만으로 해결할 수 없어, 확률적 판단이 필요하다.

### 적/ 장애물/ 아이템 등의 행동
벌레
- 플레이어의 적 역할
- 위치가 숨겨져 있다.
- 플레이어의 실수를 즉시 패배로 연결한다.
- 플레이어가 숫자를 분석하도록 유도한다.
